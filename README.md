## 使用方式

1. 打开本仓库链接并登录自己的 GitHub 账号。
2. 点击需要查看的文件。
3. 内容更新后，刷新页面即可看到最新版本。

## 更新方式

由 Ferrari 在本地维护源文件，运行：

```powershell
D:\睿谊的WPS\Ferrariwork\CRF\发布\crf-project-log\publish_crf_log.ps1
```

脚本会把最新文档复制到这里，并推送到 GitHub。
